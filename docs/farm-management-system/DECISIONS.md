# Farm Management System - Approved Demo Decisions

**Date:** 23 November 2026  
**Baseline:** URS v0.2 and FS v0.2

| Decision | Approved choice |
|---|---|
| Ownership | One owner can manage multiple farms |
| Access | Managers and workers are assigned to farms |
| Demo crops | Maize, beans, potatoes, tomatoes |
| Demo livestock | Dairy cattle, goats, sheep, poultry |
| Tracking | Individual and group; poultry defaults to flock |
| Currency | Kenyan Shillings (KES) |
| Measurements | kg, litres, tonnes, hectares, square metres, kilometres |
| Roles | Owner, Manager, Worker, System Administrator |

## Mandatory reports

1. Crop activity, inputs, harvest, and expected-versus-actual yield.
2. Livestock inventory and health events due.
3. Breeding and expected births.
4. Feed and inventory balance with low stock.
5. Tasks due, overdue, and completed.
6. Equipment maintenance due.
7. Expenses, sales, and gross margin.
